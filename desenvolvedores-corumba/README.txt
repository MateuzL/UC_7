FORMULÁRIO
O formulário envia para enviar.php.
Para envio real:
1. Abra enviar.php.
2. Troque SEU_EMAIL_AQUI@exemplo.com pelo e-mail que receberá as mensagens.
3. Publique em uma hospedagem com PHP e serviço de e-mail configurado.
4. Se a hospedagem não permitir mail(), utilize PHPMailer com SMTP.

IMPORTANTE
A versão local aberta diretamente como arquivo HTML não consegue realizar o envio PHP. Para isso é necessário executar em servidor PHP/hospedagem.
